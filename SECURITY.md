# Security policy

## Report a vulnerability

Report security issues through GitHub private vulnerability reporting: open the **Security** tab of this repository and select **Report a vulnerability**. Do not open a public issue.

We acknowledge reports within 7 days.

## Supported versions

Only the latest release gets security fixes.

cfnrain is a community fork of AWS CloudFormation Rain and is not affiliated with AWS. Do not report cfnrain issues to AWS Security.
